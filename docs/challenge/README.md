# The challenge statement

[`backend-challenge.md`](backend-challenge.md) is a verbatim copy of the statement this solution
answers. It is kept here so the requirements can be cited exactly — by a spec, by an ADR, or by a
reader checking a claim — instead of paraphrased.

It is not my work. It was published by Cocos Capital at
<https://github.com/cocos-capital/cocos-challenge>, and this copy was taken from commit
`abae7701` (last changed 2026-08-20). If the original changes, this copy does not: that is what
the commit reference is for.

The statement is the source of requirements. Where this solution departs from it, the departure is
recorded in an ADR and stated in the README — see
[ADR-0004](../adr/0004-reserve-funds-on-new-orders.md), which reserves funds on `NEW` limit orders
although the statement does not ask for it.
